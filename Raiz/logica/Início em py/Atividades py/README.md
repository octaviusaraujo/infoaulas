# Atividades de Python

Os exercícios foram organizados pelo assunto principal. As pastas `01` a `08`
contêm os temas já praticados; a partir da pasta `09` estão os próximos temas
da trilha de estudo.

## Próximos assuntos

1. `09_funcoes` — criar funções, parâmetros e retorno.
2. `10_tuplas_dicionarios_e_conjuntos` — outras coleções de dados.
3. `11_modulos_e_bibliotecas` — importar e criar módulos.
4. `12_arquivos` — ler e salvar arquivos de texto.
5. `13_tratamento_de_erros` — usar `try`, `except` e `finally`.
6. `14_programacao_orientada_a_objetos` — classes e objetos.
7. `15_testes_e_projetos` — testes automatizados e projetos integradores.
